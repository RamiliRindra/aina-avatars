# aina-avatars

Avatars pixel art des agents de l'équipage Aina, hébergés publiquement pour servir
de photos de profil aux webhooks Google Chat (qui exigent une URL publique).

| Fichier | Agent | Rôle |
|---|---|---|
| `bach.png` | Bach | Chef de projet — le point du matin |
| `curie.png` | Curie | Secrétaire — le flash hebdomadaire |

Portraits 8-bit générés avec gpt-image-2. Aucune donnée ni configuration ici : seulement des images.
